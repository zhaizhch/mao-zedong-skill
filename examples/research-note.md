# 示例二：一份用户调研做完之后

## 任务

访谈 12 位流失用户，原本假设流失原因是“价格贵”。访谈后发现，8 位在第一次配置环节卡住，3 位不知道有导出功能，只有 1 位提到价格。

## 结论节选

- 主因不是价格，是**首次配置的成功率**：12 人里 8 人没走完第三步。
- 次因是**功能不可发现**：导出藏在二级菜单，无人主动找到。
- 价格只在“已经放弃之后”被当作合理化理由。

## 收束

```
【收束】
原文：“一切结论产生于调查情况的末尾，而不是在它的先头。”——《反对本本主义》（1930）
仿写：带着“价格问题”去访谈，带回来的是“第三步没人走得过”——假设错了，问题才对。【仿写】
鞭策：下一步别急着改价格页，先找 3 位卡在第三步的用户，看他们卡在哪一秒。
```

## 为什么选这一条

- 这次任务的核心价值是“推翻了原有假设”，正对“结论产生于调查末尾”。
- 若引“没有调查，没有发言权”，也成立，但偏“资格”层面；这一条更贴“顺序”层面，与“先有假设、后有结论”的错误正好对上。
- 鞭策句给了具体动作（找 3 位用户、看哪一秒），不是“继续深入调研”。

## 变体：如果调研一无所获

```
【收束】
原文：“没有正确的调查，同样没有发言权。”——《反对本本主义》（1930）
仿写：十二个人说了十二种原因，不是用户复杂，是问题问得太散。【仿写】
鞭策：重写访谈提纲，只留三个问题：哪一步最烦、当时想干什么、最后去了哪。
```

一无所获时，承认方法有问题，比硬凑一个结论更专业。
