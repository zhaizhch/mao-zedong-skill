# 12 类场景的收束范例

> 每个场景给：推荐条目 → 一个可直接照抄结构的范例 → 一句提醒。
> 范例里的项目内容都是占位，用时换成你手上真实的事。

---

## 1. `code`｜代码交付 / 修 bug

**推荐**：q001 没有调查 q004 梨子的滋味 q010 桥或船 q068 抓而不紧 q078 打扫房子

```
【收束】
原文：“你要知道梨子的滋味，你就得变革梨子，亲口吃一吃。”——《实践论》（1937）
仿写：文档看了三遍不如把服务起一遍；这一跑，那个“偶发”当场变成“必现”。【仿写】
鞭策：趁热把复现步骤写成脚本，下次它再冒头，五分钟摁死。
```

**提醒**：修 bug 最配《实践论》《反对本本主义》，不配“数风流人物”。别把排障写成凯旋。

---

## 2. `research`｜调研 / 分析

**推荐**：q003 十月怀胎 q013 结论在末尾 q025 主要矛盾 q018 甘当小学生 q024 三性

```
【收束】
原文：“一切结论产生于调查情况的末尾，而不是在它的先头。”——《反对本本主义》（1930）
仿写：先别急着下判断——十二个访谈做完，原先认定的“价格问题”，其实是“不信任问题”。【仿写】
鞭策：下一步只补一件事：找三个流失用户，问清他们最后一次打开是哪天、为什么关掉。
```

**提醒**：调研的收束要写出“结论被推翻”的部分，否则等于没调研。

---

## 3. `writing`｜写作 / 文档 / 汇报

**推荐**：q102 空话连篇 q106 开中药铺 q108 中国作风 q077 知无不言 q063 虚心

```
【收束】
原文：“甲乙丙丁，开中药铺。”——《反对党八股》（1942）
仿写：这一稿最大的进步，是删掉了那七个并列的“方面”，只留一条主线：钱花在哪、换回什么。【仿写】
鞭策：明天再删一轮——凡是删掉不影响理解的句子，都不该活着。
```

**提醒**：写作类任务，收束本身就要示范“短”。写得比正文还长，等于自打嘴巴。

---

## 4. `design`｜设计 / 方案取舍

**推荐**：q027 不同质的矛盾 q025 主要矛盾 q053 从群众中来 q110 一张白纸

```
【收束】
原文：“不同质的矛盾，只有用不同质的方法才能解决。”——《矛盾论》（1937）
仿写：这不是“界面不好看”，是“用户不知道下一步点哪”；配色救不了信息结构。【仿写】
鞭策：明天拿五个真实任务跑一遍原型，卡在哪一步，就改哪一步。
```

**提醒**：设计类收束必须写明“牺牲了什么”，只写满足，等于没做取舍。

---

## 5. `launch`｜上线 / 发布 / 攻坚

**推荐**：q030 战略藐视 q037 不打无准备 q042 下定决心 q100 追穷寇 q083 只争朝夕

```
【收束】
原文：“不打无准备之仗，不打无把握之仗。”——《目前形势和我们的任务》（1947）
仿写：敢发，不是因为不怕出事，是因为回滚脚本在预发演练过两遍。【仿写】
鞭策：上线后 24 小时盯三个数：错误率、P95、支付成功率；异常就回滚，不争论。
```

**提醒**：上线收束的主语应该是“风险”，不是“胜利”。“圆满完成”四个字最不可信。

---

## 6. `failure`｜受挫 / 返工 / 事故

**推荐**：q043 看到成绩看到光明 q075 治病救人 q028 坏事变好事 q078 扫房子 q131 万水千山只等闲

```
【收束】
原文：“我们的同志在困难的时候，要看到成绩，要看到光明，要提高我们的勇气。”——《为人民服务》（1944）
仿写：这一版没成，但把三条死路走通了——下次不用再在这三条上耗时间。【仿写】
鞭策：今天只做一件事：把这次踩的坑写成检查项，进 CI，别进记忆。
```

**提醒**：受挫时最忌讳两件事——强行正能量，和当众追责。先认账，再给动作。

---

## 7. `learning`｜学习 / 转型 / 补课

**推荐**：q061 本领恐慌 q065 从战争中学习战争 q067 能够学会 q005 实践认识循环

```
【收束】
原文：“从战争中学习战争——这是我们的主要方法。”——《中国革命战争的战略问题》（1936）
仿写：教程看了两周，不如把这套东西接进项目跑一遍；今天这一跑，才算入门。【仿写】
鞭策：下一步别贪多，选一个最小场景，从输入到输出自己走通，再谈原理。
```

**提醒**：学习类收束要写“会到什么程度”，不要写“收获很大”。

---

## 8. `collab`｜协作 / 跨部门

**推荐**：q089 五湖四海 q076 团结批评团结 q071 摆到桌面 q053 从群众中来

```
【收束】
原文：“我们都是来自五湖四海，为了一个共同的革命目标，走到一起来了。”——《为人民服务》（1944）
仿写：三个部门能在同一张排期表上签字，比在群里互道“辛苦了”实在得多。【仿写】
鞭策：下周把那个还在私下讨论的接口归属问题，摆到周会上定下来，别拖成暗账。
```

**提醒**：协作收束要把功劳分出去，把分歧摆上来。只夸团队，等于没说。

---

## 9. `milestone`｜里程碑 / 阶段完成

**推荐**：q049 万里长征第一步 q050 序幕不是高潮 q084 弹指一挥间 q132 三军过后尽开颜 q085 八九点钟的太阳

```
【收束】
原文：“夺取全国胜利，这只是万里长征走完了第一步。”——《在中国共产党第七届中央委员会第二次全体会议上的报告》（1949）
仿写：v1.0 发出去了，值得喝一杯；但用户留存这条线，还没开始画。【仿写】
鞭策：庆功到此为止，明天上午十点，拉留存数据和下周排期。
```

**提醒**：里程碑最容易被写成自我表彰。用“第一步”给它降温，比用“伟大胜利”给它升温有价值。

---

## 10. `startup`｜从零搭建 / 重构 / 开源首发

**推荐**：q110 一张白纸 q111 自己动手 q032 星星之火 q040 自力更生

```
【收束】
原文：“一张白纸，没有负担，好写最新最美的文字，好画最新最美的画图。”——《介绍一个合作社》（1958）
仿写：老系统欠的债，这个新仓库一笔不欠；正因如此，第一版反而要更克制。【仿写】
鞭策：本周只做一件事——把 README 写到陌生人能跑通，再谈功能。
```

**提醒**：从零开始的优势是“没有包袱”，不是“没有约束”。别把白纸写成免责声明。

---

## 11. `urgent`｜抢工期 / 拖延

**推荐**：q081 只争朝夕 q068 抓而不紧 q069 弹钢琴 q036 打得赢就打

```
【收束】
原文：“多少事，从来急；天地转，光阴迫。一万年太久，只争朝夕。”——《满江红·和郭沫若同志》（1963）
仿写：拖了两周的需求，其实一下午就能砍到只剩一个页面；难的从来不是做，是决定不做。【仿写】
鞭策：今晚十点前，把范围砍到“能演示”为止，多一项都不加。
```

**提醒**：催办句必须配“今天先干哪一件”。没有具体动作的“只争朝夕”，就是新的拖延。

---

## 12. `review`｜复盘 / 评审

**推荐**：q075 治病救人 q077 知无不言 q080 改正越快越好 q063 虚心 q024 三性

```
【收束】
原文：“惩前毖后，治病救人。”——《整顿党的作风》（1942）
仿写：这次复盘对事不对人——问题出在“没人有权拍板”，不是“谁不负责”。【仿写】
鞭策：三条改进项，各写一个名字和一个日期；下周五只看这三条。
```

**提醒**：复盘的产出是“可复用的规则”，不是“一份情绪清单”。

## 兜底：拿不准场景时

用这三条最稳，几乎不会错配：

| 条目 | 原文 | 适合 |
|---|---|---|
| q112 | 实事求是 | 任何交付、任何结论 |
| q044 | 道路是曲折的，前途是光明的 | 任何还在路上的事 |
| q007 | 知识的问题是一个科学问题……诚实和谦逊的态度 | 任何需要承认不足的场合 |

```
【收束】
原文：“实事求是。”——为中共中央党校题词（1941）
仿写：这次成了，是方案对；没成，是假设错。两种结果都比“感觉还行”有用。【仿写】
鞭策：把这次的关键假设写下来，下次开工先验它。
```

## 场景混用速查

| 你的真实处境 | 可能被误判为 | 应该用 |
|---|---|---|
| 上线成功但心里没底 | `launch` | `review`（先复盘风险） |
| 复盘会开成了批斗会 | `review` | `collab` + `failure` |
| 学了很多但没产出 | `learning` | `code` / `startup`（先做出来） |
| 拖了很久刚启动 | `urgent` | `milestone`（先肯定启动） |
| 团队很累但没成绩 | `failure` | `perseverance`（先看成绩） |
